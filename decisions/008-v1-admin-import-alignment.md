- 相关模块：后端（BFF）、数据层、前端（/admin）

## 摘要

管理员希望把从家教网抓取/复制的原始文本（参考 `你好.txt`）批量生成家教单，系统按字段自动匹配并入库。先盘点目标字段、读原始文本形态，再经四问对齐确认：

| 决策点 | 结论 |
|---|---|
| 输入形态 | **纯文本粘贴**（如 `你好.txt` 自由格式），系统从文本识别标签并抽取字段（非 CSV 列导入） |
| 解析策略 | **规则/正则**（纯函数 + 映射表，可解释、可单测、零外部依赖与成本） |
| 交互流程 | **预览-确认-入库**：解析后展示预览表，管理员逐格编辑/勾选后再批量写入；解析错误标红 |
| 本次范围 | **全链路**（解析引擎 + BFF 批量导入接口 + /admin 导入页）；但本期只落盘设计，不写实现代码 |

| | `mode` | 枚举 online / offline |
| | `region` | 文本≤40，详细地点 |

| | `student_info` | 文本≤500，学员情况 |
| 可选 | `hourly_rate` | 整数 0–10000（面议/按次→null） |
| | `student_gender` | 枚举 male / female / unknown（默认 unknown） |
| | `rate` | 文本≤40，价格原文（如「70元/小时」） |

## 解析管线（4 步）

1. **切分 segment**：整段文本按单子边界切成 N 条记录（标题行/编号起始；跳过 emoji 装饰行与 `#` 注释行）。
2. **抽取 extract**：每条按标签正则取 `label → value`；标签缺失时按就近/上下文兜底。
3. **归一 normalize**：原始值转 schema 类型（见下「解析规则映射」）。
4. **校验 validate**：套 `GigCreate` 校验，缺必填 / 超长 / 枚举非法 → 该格标红，给出预览。

## 解析规则映射（核心）

| 目标字段 | 规则 | 示例 |
|---|---|---|
| `grade_level` | 年级词→enum | `初二`→junior、`准高一`→senior、`六年级`→primary、`五年级`→primary、`三年级`→primary、`大一`→college |
| `subject` | 缩写展开+拼接 | `语数英`→语文·数学·英语、`数理化`→数学·物理·化学；`文科一个 理科一个` 模糊，留人工 |
| `district` | ①`X区.`/`X区`前缀正则→enum；② 无前缀走手工映射表 | `岳麓区.梅溪湖壹号`→yuelu；`北部湾`/`汉唐·翰林府1期`/`观沙岭`/`君康家园`/`火车站`/`润和星河玥`/`保利天汇`/`长郡外国语`→见下 |
| `hourly_rate` | 取「数字+元/小时」整数；区间取下限或均值；`一次两个小时`折算；`左右`取近似 | `70元/小时`→70、`100-110元/小时`→100(或均值105)、`60一小时一次两个小时`→60、`50左右`→50；面议/按次→null |
| `student_gender` | 性别词 | `初二、女`→female、`男女不限`→unknown、`男`→male；缺省 unknown |
| `rate` | 薪水原文原样保留 | `70元/小时` |
| `mode` | 默认 offline（家教单几乎全上门）；文本显式「线上」才 online | — |
| `contact_wxid` | **v1 不强行猜**：`#` 注释不全是微信号，可靠性低 → 留空/默认，交人工补 | — |

## 默认假设（可被推翻）

- **去重**：按编号/`title` 归一后去重（`你好.txt` 中 `10034679`/`10034617`/`10034592` 各出现 2 次）。
- **必填解析不出**：该条整体标红、不入库，让管理员在预览表补；可选项留空/取默认。
- **异常结构兜底**：`8.27 10034679`（接送/伴读型，字段顺序全乱、用数字列表）先走通用规则，解析不出的字段标红交人工。
- `mode` 默认 offline；`student_gender` 默认 unknown；`contact_wxid` v1 留空。

## 不做（v1 范围外）

- LLM 解析（本期选规则/正则）。
- CSV/Excel 列导入（本期只纯文本粘贴）。
- 全自动入库（需人工预览确认）。
- 微信号自动提取（不可靠，交人工）。
