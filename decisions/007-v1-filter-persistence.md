## 摘要

用户在 v0.4.0 筛选上线后报告：点进单子详情再退回列表，筛选被清空。经两轮带推荐对齐确认后实施：

| 决策点 | 结论 |
|---|---|
| 根因 | 首页筛选全部为组件内 `useState`；React Router 切路由时 `HomePage` 卸载，状态随组件销毁。详情页返回按钮是 `Link to="/"` 硬导航（非 history.back），因此 URL 参数方案也需同步改详情页 3 处返回链接 |
| 方案 | **sessionStorage**（key `cs-tutoring.list-filters.v1`）而非 URL 参数——H5 免登录浏览场景无分享筛选链接需求；只改 `HomePage.tsx` 一个文件，回归面最小 |
| 恢复范围 | 筛选值（区域/科目/年级/模式/时薪/性别/排序）+ 页码全部恢复；「更多筛选」展开状态不持久化（返回后收起，不遮挡列表） |
| 生命周期 | 进详情/返回、刷新页面均保留；关闭页面（tab 会话结束）重置为默认 |
| 科目防抖修正 | 原防抖 effect 每次 350ms 后都重置页码；改为仅在输入值确实变化时重置（恢复时 `subjectText===subject` 不重置，避免恢复的页码被打回第 1 页） |
| 数据安全 | 恢复时对枚举值/文本长度/页码做合法性校验，脏数据或旧格式回默认值，不污染状态 |
